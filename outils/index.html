  1. En ligneCliquez sur « Ouvrir l’outil ». Rien à installer. Vos données restent dans ce navigateur, sur cet appareil.
  2. Comme une appliDans l’outil, bouton « Installer l’appli » (Android, ordinateur avec Chrome ou Edge). Sur iPhone : Partager, puis « Sur l’écran d’accueil ». Elle marche ensuite sans connexion.

Vos données

Les outils ne créent pas de compte et n’envoient vos devis, vos clients et vos prix à aucun serveur, ni chez Onklaud ni ailleurs. Tout est enregistré dans le navigateur de l’appareil utilisé. Si vous videz les données du navigateur, elles disparaissent : utilisez l’export régulièrement.

Seule exception : la dictée vocale du devis dicté utilise la reconnaissance vocale de votre navigateur. Avec Chrome, l’audio est transmis à Google pour être transcrit. Si vous préférez, tapez au clavier : le résultat est le même.
